新词自学习 —— 让分词器认识本领域的新说法
中文分词靠词典，但网信领域的说法一直在变（新出现的治理术语、 新设的机构简称），词典不更新就会被切碎， 检索时按词组匹配不到，统计时词频也被稀释。
这里用无监督统计法（凝固度 + 邻字自由度 + 可切分性）从 语料里挖候选词，由你勾选后写进 jieba 用户词典 —— 写完立即生效且重启后仍在。
勾选这一步有 🤖 AI 预勾选可以代劳：AI 逐个判断每个候选 该收该弃并给一句话理由，建议采纳的会自动勾上。 但它只给建议 —— 词典是持续影响后续所有检索与统计的东西， 误写进去不会报错、也很难被发现，所以最终仍然由你点「采纳」。

新词候选

三个指标：凝固度越高说明这个词「该粘在一起」； 邻字熵越高说明左右能接的字越杂（真词特征）； 领域是本项目加权（网信术语/机构后缀优先上浮）。 这是候选不是结论——统计能保证「大概率是词」， 保证不了「这个领域该收」，所以由你定夺。
门槛是「凝固度 或 邻字熵」过线即可，收敛得比较宽； 熵显示 — 表示该侧熵为 0，有两种成因： 候选正好在句子首/末（那侧没有相邻字），或该侧邻字全都相同 （说明它总出现在同一个固定上下文里，更像短语片段）。 两种都是真实取值，不是算错了。
