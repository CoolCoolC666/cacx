# 分析任务指南 · 总览

> 本目录是**分析任务的执行手册**：每一份 `00`–`05` 是一道独立任务的提示词，
> 整段复制给你的智能体（豆包 / Kimi / DeepSeek / ChatGPT 等）即可开工。
> 载体是**分发版压缩包**（`数据包/` 是跑不动网站时的兜底）。

## 一、拿到手的是什么：分发版压缩包

主文件：`网站程序\cacx-分发版-20261017.zip`（约 500 MB，另有约 410 MB 的瘦身包）。

解压后就能跑起和演示用的一模一样的网站：

1. 解压到**不含空格与中文括号**的路径（例：`D:\cacx`）
2. 双击 `启动cacx.bat`
   - 本机有 Python 3.10+ 且能联网 → 用你自己的 Python，**首次自动装依赖**（1-2 分钟），然后起服务、开浏览器
   - 本机没有 / 版本太老 / 连不上网 → 自动改用包内自带的 `runtime\python.exe`，**什么都不用装、不用联网**
   - 也就是说：**什么都不装也能直接双击跑起来**
3. 浏览器地址 `http://127.0.0.1:8770/`

> 想用可选的 MCP 功能需要 Python 3.10+，而且它**不会自动安装**（窗口里会给出命令）。
> 不装 MCP 不影响网站任何其他功能。

包里有什么、没什么，解压后先看根目录的**《【使用前必看】README.txt》**。

拿到包里能直接用的（不写一行代码）：

| 页面 | 能干什么 |
|---|---|
| 检索 | 中文整句/分词两种模式，命中高亮，点标题看全文 |
| 样本配置器 | 定「栏目 + 区间 + 篇数上限」抽样本，**一键导 CSV（含抽样口径页脚）** |
| 数据面板 | **七张图**（趋势 4 张 + 权责边界 3 张），每张 ⬇PNG / ⬇CSV，右上角还能「⬇ 面板 HTML」导出离线归档版 |
| 关系图谱 | R1 写入后即可**点关系回溯原文句子与链接**——要展示的就是这个页面 |
| 设置 | 粘贴自己 AI 工具的配置即可导入密钥；不配 AI 也能完成全部任务 |

连 AI 智能体（可选，推荐 R1 用）：MCP 配置片段

```json
{"mcpServers": {"cacx": {
  "command": "python", "args": ["-m", "cacx.mcp_server"],
  "cwd": "D:\\cacx 解压后的分发版目录"}}}
```

**兜底**：压缩包传不动、或电脑实在装不了 Python，退回
`数据包/`（约 46 MB：小库 + CSV + 字段说明），所有任务的 CSV 路线都写得通。

## 二、⚠️ 最先启动：定样本口径

分析要求是「任选一个栏目，300-500 篇，2024 年以来」。
**2024 年以来 25 个栏目没有任何栏目天然落在 300-500 篇**（最多 1639，最少 14）。

所以样本 = **栏目 + 时间窗 + 篇数上限** 三件事一起定：

- 时间窗 `2024-01-01` ~ `2099-12-31`（2024 年至今，**含 2026**）
- 篇数上限 300 / 400 / 500
- 抽样策略**必须用分层**（按年份）——「最近 N 篇」实测会把 **2024 整年丢掉**

定案方式：走 `00-选栏目投票.md` 的流程 —— 先出一份《栏目选择建议》，
再由所有参与方投票确定，**投票结果出来后当天广播三项参数**。
三项参数影响 R1/R3/R4/R5 全部任务，口径不一致成果拼不上。

## 四、回传与合并（压缩包模式）

各人的网站/数据库都在**自己解压的那份包**里，`entities/relations` 写的是自己本地库。
所以：

1. **CSV 是唯一交接口**：R1 走完 MCP 也要从 `cacx_list_entities()/cacx_list_relations()`
   导出 CSV 交回；R3/R4 交 CSV + PNG + README；R5 交 md。
2. 统一命名 `姓名-编号-任务名.zip`，走群文件回收（不用 GitHub）。
3. 收齐 CSV 后导入**主库**（合并逻辑幂等：同一篇同一关系不会翻倍）。
   演示当天用**主库**这份包，别用各人的本地库。
4. **别把改过的 db 发回来**（200 MB 传输慢且难合并），要发就发 CSV。
5. 文件一律 **UTF-8 带 BOM**，Excel 双击不乱码。

## 六、风险提示

| 风险 | 影响 | 应对 |
|---|---|---|
| 跑不起来网站 | 拿不到样本 | 先核对 Python PATH 勾选；再不行走 `数据包/` CSV 兜底 |
| 压缩包传不动 | 开工延迟 | 现场帮传 / 共享网盘 / 数据包兜底 |
| 口径未定就各自开工 | 成果拼不上，作废 | 00 限时 1 天，不定案不开工 |
| R1 质量差 | 图谱和报告都塌 | 「质量>数量」，随机 10 条自查；审核方复核 |
| 各人口径不一致 | 合并对不上 | 一律以 CSV 交回，主库只认审核方导出的 |
| 报告写不完 | 缺 1 项材料 | 设硬节点；审核方兜底润色 |
| 图表投影看不清 | 现场翻车 | 面板已修（不遮挡、字号够）；R2 走查再兜一层 |

**兜底原则不变**：任何一份成果没按时到，不要等——审核方接过来补完。
工程侧（一条命令运行、面板、导出、图谱页、样本配置器）已完成并实测，
时间应该花在**核数据和报告**上，不是修界面。
