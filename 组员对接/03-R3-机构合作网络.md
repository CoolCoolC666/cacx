## 第一步：先把联合发文挖准（这是全部工作的地基）

数据包里有 222 篇标题含「联合/印发/会同」的线索，但**机关名要自己抽**。

方法建议（按可靠性从高到低）：

1. **看正文开头**：gov 公文正文首段通常有
   「……为贯彻落实……经国务院同意，现将……印发给你们」
   或「XX部、YY局联合印发」
2. **看标题结构**：「XX部  YY局 关于印发……的通知」→ 前缀就是联合机关
3. **看正文署名**：文末常有「（来源：XXX）」或落款单位

**判据要求**：每个联合发文结论，你都要能指出它出自哪篇哪句。

## 交付物

### 文件 1：`机构合作.csv`

| 列 | 说明 |
|---|---|
| `org_a` | 机构 A（统一写法，如「中央网信办」） |
| `org_b` | 机构 B |
| `coop_count` | 两者共同出现（联合发文）的篇数 |
| `is_cac` | 是否涉及网信办（Y/N）——老师问的就是这个 |
| `example_ids` | 示例文章 id（逗号分隔，3 个以内） |
| `example_titles` | 对应标题 |
| `example_url` | 对应原文链接 |
| `evidence` | **支撑该关系的原文句子**（逐字照抄） |

> ⚠️ 机构名**必须统一写法**。「国家互联网信息办公室」「中央网信办」
> 是同一个机构，要归并成同一个字符串，否则网络会裂成两半。
> 归并规则写进 README。

### 文件 2：`机构名单.csv`

所有出现过的机构 + 类型：

| 列 | 说明 |
|---|---|
| `org_name` | 统一后的机构名 |
| `org_type` | 网信办 / 中央部委 / 地方政府 / 其他 |
| `coop_degree` | 参与联合发文的篇数（用于排序画网络图） |
| `sample_evidence` | 出现该机构的示例原文 |

### 文件 3：`机构合作网络.png`

**一张能放进 PPT 的合作网络图**。

要求：
- **中心节点是网信办**（老师问的就是它和谁合作）
- 其他机构按 `coop_count` 大小定节点大小
- **边的粗细 = 合作篇数**
- 图例说明节点颜色含义
- **别放 50 个节点糊成一团**，太弱的边可以不画

要求 PNG / SVG 格式，**分辨率够放进投影**（宽度 ≥ 1600px）。

### 文件 4：`README-机构合作.md`

- 你的机关名归并规则
- 抽了多少篇、多少条合作边
- **人工复核了哪几条**、机器抽的占多少比例
- 你认为哪些结论最可能不准

## 硬性要求

1. **「网信办联合发文」和「网信办单独发文」的比例必须给出来。**
   这是老师「权责边界」那部分的直接证据：
   有多少是网信办能独立做的，多少必须拉别人一起做。

2. **数字要有出处**：每条关系都要能指回原文。

3. 不要交 Python 脚本了事——**要 CSV 数据本身**。
