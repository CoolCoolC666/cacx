## 一、组员拿到的是什么：分发版压缩包

主文件：`网站程序\cacx-分发版-20261012.zip`（约 255 MB，以群里最新一包为准）。

解压后组员自己就能跑起**和演示用的一模一样的网站**：

1. 解压到**不含空格与中文括号**的路径（例：`D:\cacx`）
2. 装 Python 3.8+（推荐 3.12 / 3.13；安装时**务必勾选 "Add Python to PATH"**。只有可选的 MCP 功能需要 3.10+，不装不影响其他任何功能）
3. 双击 `启动cacx.bat` —— 首次自动装依赖（1-2 分钟），然后起服务、开浏览器
4. 浏览器地址 `http://127.0.0.1:8770/`

包里有什么、没什么，解压后先看根目录的**《【组员请先看】README.txt》**。

组员在包里能直接用的（不写一行代码）：

| 页面 | 能干什么 |
|---|---|
| 检索 | 中文整句/分词两种模式，命中高亮，点标题看全文 |
| 样本配置器 | 定「栏目 + 区间 + 篇数上限」抽样本，**一键导 CSV（含抽样口径页脚）** |
| 数据面板 | **七张图**（趋势 4 张 + 权责边界 3 张），每张 ⬇PNG / ⬇CSV，右上角还能「⬇ 面板 HTML」导出离线交作业版 |
| 关系图谱 | R1 写入后即可**点关系回溯原文句子与链接**——老师要的就是这个页面 |
| 设置 | 粘贴自己 AI 工具的配置即可导入密钥；不配 AI 也能完成全部任务 |

连 AI 智能体（可选，推荐 R1 用）：MCP 配置片段

```json
{"mcpServers": {"cacx": {
  "command": "python", "args": ["-m", "cacx.mcp_server"],
  "cwd": "D:\\cacx 解压后的分发版目录"}}}
```

**兜底**：255 MB 传不动、或电脑实在装不了 Python 的组员，退回
`组员数据包/`（约 46 MB：小库 + CSV + 字段说明），所有任务的 CSV 路线都写得通。

## 二、⚠️ 最先启动：投票定样本口径（全组 5 人投票）

老师要「任选一个栏目，300-500 篇，2024 年以来」。
**2024 年以来 25 个栏目没有任何栏目天然落在 300-500 篇**（最多 1639，最少 14）。

所以样本 = **栏目 + 时间窗 + 篇数上限** 三件事一起定：

- 时间窗 `2024-01-01` ~ `2099-12-31`（2024 年至今，**含 2026**）
- 篇数上限 300 / 400 / 500
- 抽样策略**必须用分层**（按年份）——「最近 N 篇」实测会把 **2024 整年丢掉**

流程：**组员甲限时 1 天出《栏目选择建议》→ 群里 5 人投票 → 当天广播三项参数**。
三项参数影响 R1/R3/R4/R5 全部任务，口径不一致成果拼不上。
投票建议用接龙或投票小程序，**少数服从多数，你的一票同权**。

## 四、回传与合并（压缩包模式的新规矩）

各人的网站/数据库都在**自己解压的那份包**里，`entities/relations` 写的是自己本地库。
所以：

1. **CSV 是唯一交接口**：R1 走完 MCP 也要从 `cacx_list_entities()/cacx_list_relations()`
   导出 CSV 交回；R3/R4 交 CSV + PNG + README；R5 交 md。
2. 统一命名 `姓名-编号-任务名.zip`，**钉钉群文件**回收（不用 GitHub）。
3. 你收齐 CSV 后导入**主库**（合并逻辑幂等：同一篇同一关系不会翻倍）。
   演示当天用**你的主库**这份包，别用组员的本子。
4. **别把改过的 db 发回来**（200 MB 传输慢且难合并），要发就发 CSV。
5. 文件一律 **UTF-8 带 BOM**，Excel 双击不乱码。
