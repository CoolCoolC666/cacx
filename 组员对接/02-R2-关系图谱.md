## 技术要求（重点，省掉你的踩坑时间）

### ⚠️ 不要引入构建工具

**不要** React / Vue / npm / webpack / D3 的安装教程。
交付物必须是一个 `.html` 文件，组员老师双击就能看。

### 推荐做法

用 `ECharts` 或 `D3` 的**单文件 CDN 版**，把整个库内联进 HTML。
好处是**完全离线可用**——教室没网也能演示。

如果智能体给你的是一堆 `npm install` 步骤，**明确拒绝**，要求改成单文件方案。

### 图的交互细节（这些是加分项）

1. **节点按类型着色**：
   - 机构 = 蓝
   - 政策 = 紫
   - 治理问题 = 红
   - 措施 = 绿
   （自己定，但要**图上有图例**说明哪个颜色是什么）

2. **边的类型要能区分**：四种关系至少用不同线型或颜色。
   点击某类关系时，其他边变淡（聚焦），这样 200 条边的图才看得清。

3. **侧边栏内容**（点边后显示）：
   ```
   关系类型：针对
   中央网信办  →  网络谣言
   原文句子：「……（这里逐字显示 evidence_sentence）」
   来源文章：（标题，做成链接可点）
   [打开原文 ↗]
   ```

4. **规模控制**：如果关系超过 300 条，默认只画 **出现频次 Top 60** 的节点，
   其余折叠成「显示更多」。全画出来是没法看的。
