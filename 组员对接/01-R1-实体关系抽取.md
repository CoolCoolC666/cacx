## 四类实体（老师指定的）

| 类别 | 说明 | 例子 |
|---|---|---|
| **机构** | 发文/执行/协同的政府部门、组织 | 中央网信办、公安部、市场监管总局 |
| **政策** | 法律法规、规划、意见、办法、通知 | 《网络安全法》《XX行动计划》 |
| **治理问题** | 文章针对的负面/待治理的社会问题 | 网络谣言、未成年人沉迷、虚假信息 |
| **措施** | 治理动作与手段 | 开展专项行动、约谈平台、处罚、下架 APP |

## 需要抽的关系（老师点名的四类）

| 关系 | 问的是什么 | 边的方向 |
|---|---|---|
| `发布` | **谁**发布了这篇/这项内容 | 机构 → 政策 |
| `针对` | 机构针对**什么问题** | 机构 → 治理问题 |
| `采取` | 采取了**什么措施** | 机构 → 措施 |
| `联合发文` | **和谁**一起发的 | 机构 → 机构 |

## 交付物（严格按这个交）

### 文件 1：`entities.csv`

所有去重后的实体。

| 列 | 说明 |
|---|---|
| `entity_id` | 唯一编号，如 `E0001` |
| `entity_name` | 实体名称（用原文里的写法，不要自己改称谓） |
| `entity_type` | 只能是 `机构` / `政策` / `治理问题` / `措施` 四选一 |
| `mention_count` | 在该栏目样本里出现了多少次 |
| `first_seen` | 最早出现的日期 |

### 文件 2：`relations.csv`

**这是老师最看重的文件。**

| 列 | 说明 |
|---|---|
| `relation_id` | 唯一编号 |
| `relation_type` | `发布` / `针对` / `采取` / `联合发文` |
| `src_id` | 主体 → 对应 `entities.entity_id` |
| `src_name` | 主体名称（**冗余一份，避免 join 出错**） |
| `dst_id` | 客体 → 对应 `entities.entity_id` |
| `dst_name` | 客体名称 |
| `evidence_article_id` | 支撑这句的文章 id |
| `evidence_sentence` | **原文里那一句**（必须逐字照抄，不许改写、不许翻译） |
| `evidence_url` | 原文链接 |
| `confidence` | `高` / `中` / `低`，你自己判断 |

> ⚠️ **`evidence_sentence` 是这个作业的命门。**
> 老师要求「点每条边能看到原文句子和来源链接」。
> 没有原文句子的关系，等于没有证据，**宁可少抽，不可编造**。

## 执行要求

1. **先抽样 20 篇通读**，摸清这批文章的写法规律，再决定批量方案。
   直接上来就跑正则，大概率抽出一堆垃圾。

2. **正文太短的跳过**：`chars < 200` 的文章基本抽不出东西，记录下来即可，不要硬抽。

3. **覆盖率说明**：不必强行覆盖样本里的每一篇。
   抽 150 篇以上、关系总数 300 条以上，就是合格。
   **质量比数量重要**——老师会点开边看原文，抽错一条就露馅。

4. **中文 CSV**：编码用 **UTF-8 with BOM**（Excel 双击才不乱码）。
   Python 里就是 `open(..., encoding='utf-8-sig', newline='')`

5. **诚实标注**：机器抽的和人工复核的要分开说。
   在 README 里写清楚比例。老师问起来，你答得上来。
