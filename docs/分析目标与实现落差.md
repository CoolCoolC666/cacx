## 一、需求原文

### 标题
**网络舆情概述**

### 任务正文

> 从中央网信办（cac.gov.cn）和浙江网信网（zjwx.gov.cn）任选一个栏目，
> 采集 300-500 篇文章 —— 抽取其中 **机构、政策、治理问题、措施** 四类实体之间的
> 文本关系（谁发布？什么政策、机构针对什么问题、采取了什么措施、和谁联合发文），

> 它的**权责边界在哪里？**

### 要求（原文编号 1）

1. **采集 2024 年以来的数据**，网站要呈现以下内容：

   - **关系图谱**：四类实体的关系图，点每条边能看到**原文句子**和**来源链接**
   - **机构合作网络**：哪些部门常和网信办**联合发文**
   - **时间轴**：发文量**【存疑：与】**主题随时间的变化
   - **浙江对照（选做）**：cac 与 zjwx 同主题对照

| 演示 | 5 分钟以内：演示网站 + 现场点 2 条关系回溯原文 + 讲一个发现 |

## 二、关键解读（这几条决定后面怎么做）

### 1. 要的不是「检索工具」，是「关系抽取系统」

任务的核心动词是**抽取**，不是采集、不是检索：
四类实体（机构 / 政策 / 治理问题 / 措施）之间的**文本关系**。

我们现有的 `cacx` 主体能力是**检索 + 摘要 + 数据面板**。
**实体关系抽取在起点是 0** —— 这是最大的缺口，也是本次任务真正的技术难点。

### 2. 「点边看原文句子」= 必须保留证据链

每条关系都要能点回**原文句子**。这意味着不能只存 `{主体, 关系, 客体}`，
必须同时存下**支撑这句话在原文中的位置**（段落 / 句子的原文 + 出处 URL）。

这一条与已有的「一键回溯原文」设计思路一致，可以复用。

### 3. 「任选一个栏目」意味着要**收敛范围**

300-500 篇 = 只取**一个栏目**，不是全站。
现在库里有 28999 篇，演示时「全站」是没法讲的，必须先选栏目、定范围。

### 4. 「联合发文」是可自动识别的强信号

机构合作网络靠的是**发文主体**信息：
`{发文机关 A, 发文机关 B, 篇名, 日期, URL}`。
「和谁联合发文」在公文标题里通常直接出现（「……关于印发 X 与 Y 联合……的通知」），
是结构化程度最高的一类关系。

### 5. 「2024 年以来」与现有数据不冲突，但要显式筛选

库里有 2000 年起的旧数据（`trend` 接口实测最早 2000-09）。
展示时必须按 `year >= 2024` 过滤，否则时间轴会被二十年前的数据压扁。

### 6. 交付物里**报告和网站是两份独立的东西**

要求列的是四项材料，不是一个程序的四个功能。
尤其「角色画像 / 权责边界」这类**结论性表述**，不能只做成页面上的一个 Tab 了事。

缺的是「关系抽取 + 图谱 + 报告 + 演示」这四件 —— 恰好是评审真正在考的东西。**

## 四、需要向评审方口头确认的存疑点

1. 报告里「权责边界（独立做了什么 / 联合谁……）」的后半句具体要求
2. 「任选一个栏目」—— 是**任选一个站点的一个栏目**，还是两个站点各选一个
3. 关系图谱是否要求**特定呈现形式**（如 D3 力导向 / 静态图 / 表格即可）
4. 「浙江对照」标注为选做，做了是否加分
