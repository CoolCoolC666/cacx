**当前语料：28917 篇 / 3827 万字**（中国网信办 23291 篇 + 浙江网信网 5626 篇），

## 👋 给组员：这是什么，你能拿它干什么

### 你拿到的三样东西

| | 说明 |
|---|---|
| **语料库** | 两站 2024 年至今的文章全文 + 栏目/日期/来源等元信息，已在本地存好 |
| **检索界面** | 浏览器里按关键词、栏目、年份、日期筛，命中词标黄，可导出 CSV |
| **AI 摘要** | 4513 篇已有摘要（含标签、情感倾向、涉及机构），可搜索可导出 |

### 典型的作业场景

- **写论文找素材**：检索「数据出境」「未成年人网络保护」，导出 CSV 做词频/时间分布分析
- **做舆情趋势分析**：数据面板七张图（按年/按月分布、栏目 Top12、检索行为、
  治理问题分布、高频机构、联合发文月度趋势），直接看某议题的热度变化
- **抽样阅读**：检索结果点开就是全文 + 摘要，不用反复开网页
- **做语料统计**：栏目分布、字数分布、情感倾向分布都在库里，可以直接导出做量化

### 怎么分工建议

1. **每人各自解压一份分发包**、各自双击 `启动cacx.bat`——包带全量数据，互不依赖（推荐）
2. 想只看一台的（省磁盘）：由一个人把设置页 `app.host` 改成 `0.0.0.0`，
   其他人用**他的局域网 IP**:8770 访问。只在可信内网这么做，别挂公网
   （注意：这服务默认只监听 127.0.0.1，只对本机开放；要共享给同组其他电脑，
   需要改配置成 `0.0.0.0`，但那就要在**可信的内网**里做，别直接暴露到公网）
3. 或者各自解压一份分发包，各用各的（数据库 500MB，占空间）

## 🚀 三步跑起来

### 第 1 步：解压 / 下载

解压到**不含空格与中文括号**的路径，例如 `D:\cacx` 或 `D:\网信办项目\`。
（路径里有特殊字符会让 `.bat` 脚本出错，这是 Windows 的老毛病）

需要 **Python 3.8 及以上**（推荐 3.12 / 3.13）。3.8 / 3.9 能跑网站全部功能，只是部分包要现场编译、偶尔慢；唯一需要 3.10+ 的是**可选的 MCP 功能**，不装不影响其他任何功能。没装的话去 python.org 下载，
安装时**务必勾选 "Add Python to PATH"**。

### 第 2 步：双击启动

```
start-cacx.bat
```

它会自动装依赖 → 启动服务 → 自动打开浏览器。就这么简单。
首次运行装依赖需要几分钟，之后再双击就是秒开。

**关闭那个黑色命令行窗口 = 关闭服务。**

### 第 3 步：开始用

浏览器打开 **http://127.0.0.1:8770/**

界面上一排标签：`检索` · `数据面板` · `样本配置器` · `关系图谱` · `设置` · `AI 摘要` · `数据同步`

```
data/cacx.db      约 500 MB，含全部文章与摘要
```

- 想从零开始：删掉 `data/cacx.db`，然后 `python -m cacx sync` 重新抓
- 抓取默认从 **2024-01-01** 开始（两站一致），可在设置页改

## 🔑 AI 功能要先自己配密钥

**分发包里不含任何人的密钥**（也不该含）。要用 AI 摘要/标签功能，
需要用**你自己的** API 密钥：

1. 点右上角 **⚙ 设置**
2. 填：供应商 → 接口地址 → 模型名 → **你的密钥**
3. 或直接把你其它 AI 工具的配置（`.mcp.json` 等）粘贴到设置页顶部，
   它会自动认出密钥/地址/模型，不用手抄
4. 点「测试连接」确认通了

密钥存在**你自己电脑**的 `config/settings.json` 里，只写入、不回显
（保存后输入框只显示「已配置（N 字符）」）。

> **安全提醒**：密钥不要发到群里、不要贴到代码里、不要提交到仓库。
> 本项目的 `.gitignore` 已经把 `config/settings.json` 排除了，
> 但如果你手动 `git add -f`，密钥就会进版本历史且删不掉。

**生成摘要会消耗 API 配额**。所以程序默认「只预览不执行」——
生成类操作一律先给你看预览，确认无误再点真正生成。批量跑之前
建议先用「预览」按钮看一眼命中了哪些。

## 🔍 常用操作速查

### 网页上

| 想做什么 | 怎么做 |
|---|---|
| 找文章 | 检索页填关键词 → 回车 |
| 限定范围 | 站点 / 栏目 / 年份 / 日期区间，可任意组合 |
| 看趋势 | 「数据面板」标签 → 七张图，每张可 ⬇PNG / ⬇CSV，右上角还能导出离线 HTML |
| 配作业样本 | 「样本配置器」标签 → 栏目 + 时间窗 + 篇数上限 + 分层抽样 → ⬇CSV（带口径页脚） |
| 看实体关系 | 「关系图谱」标签 → 点一条关系回溯原文句子与链接（数据由 MCP/导入写入） |
| 让 AI 干活 | 智能体 MCP 配置 `python -m cacx.mcp_server`（cwd 指到解压目录），22 个工具 |
| 看摘要 | 「AI 摘要」标签，可按摘要内容/标签搜索 |
| 导出结果 | 检索页点「导出」→ 选 CSV 或 JSONL |
| 抓最新文章 | 「数据同步」标签 → 选站点/年份 → 开始 |
| 体检数据 | 设置页附近有「接口自检」，看两站接口是否还通 |

### 命令行（进阶，可跳过）

```bash
python -m cacx stats                          # 数据体检 + 分布统计
python -m cacx search "数据出境" -n 10        # 命令行检索
python -m cacx export "清朗" -o 清朗.csv      # 导出 CSV
python -m cacx show 514                       # 看第 514 篇全文
python -m cacx doctor                         # 接口自检
python -m cacx sync --year 2026               # 只同步 2026 年
python -m cacx serve                          # 启动服务
```

装成命令行（可选）：`pip install -e .`，之后直接用 `cacx stats`。

## ❓ 常见问题

**Q：双击 bat 闪一下就没了 / 报错**
A：路径里有空格或中文括号，换成 `D:\cacx` 再试。
或者手动开命令行执行 `pip install -r requirements.txt` 看真实报错。

**Q：端口 8770 被占用**
A：设置页改 `app.port`（比如 8899），之后访问 `http://127.0.0.1:8899/`。

**Q：中文搜「清朗」搜不到？**
A：能搜到。这个工具对 2 字词做了特殊处理，会自动从全文索引降级到
LIKE 扫描，代价是慢一点（约 57ms），但不会漏。

**Q：摘要页面显示「内容审查拦截」**
A：这是 AI 服务商自己家的内容安全策略拦的，**重试一万次也一样**，
不是你的配置问题。需要的话可以用清单里的「✍ 人工补录」自己写一段摘要。

**Q：想给组员共享服务**
A：把配置里 `app.host` 从 `127.0.0.1` 改成 `0.0.0.0`，同组的电脑就能
用你的局域网 IP 访问。**只在可信内网这么做**，别直接暴露到公网。

**Q：数据库能直接用 Excel 打开吗？**
A：不能直接双击（SQLite 需要工具）。可以导出 CSV/JSONL 再用 Excel。
推荐用 [DB Browser for SQLite](https://sqlitebrowser.org/) 直接查看。

**Q：抓取会不会把网站抓崩？**
A：默认限速 0.35 秒/次请求，只抓公开列表页。同源站点会自动去重，
不会重复抓。不建议调高并发。

## 📁 项目结构

```
cacx/
├── config.py       配置持久化（密钥掩码、环境变量覆盖、可从外部导入）
├── db.py           SQLite schema + FTS5 全文索引 + 并发安全
├── importer.py     既有 json 语料批量入库
├── purge.py        批量删除（两阶段二次确认）
├── placeholder.py  正文未入库的占位条目可见 + 定向补抓
├── collector/      两站采集器 + 同步/自检编排
│   ├── cac.py      中国网信办（/cms/JsonList JSON 端点）
│   ├── zjwx.py     浙江网信网（jpaas 端点）
│   ├── generic.py  通用站点采集器（可自行加站点）
│   └── classify.py 失败分类（导航/站外/脏数据…）
├── ai/             AI 适配层 + 摘要/标签/诊断/中断恢复
├── web/            FastAPI 服务 + 单页前端
├── cli/            命令行入口
└── mcp_server.py   MCP server（可让 AI 工具直接调本项目）

config/    settings.example.json（模板，已提交）
           settings.json（你自己的配置，gitignore，不入库）
data/      cacx.db（数据库，gitignore）
日志/      开发留痕文档（每轮改了什么、为什么）
docs/      工程文档
（测试）/  测试脚本 + 开发期的一次性脚本（不随分发包走）
```

> **测试为什么不在根目录**：根目录一度堆了 70 个 `_*.py` + 31 个
> `tests_*.py` + 30 个日志，真正属于工程的只剩上面那几行 ——
> 想知道「这功能改了哪个文件」得先翻一遍噪音。现在测试与开发脚本
> 全在 `（测试）/`，根目录只留工程本体和 4 个 bat。
> 一键整理用根目录的 `dev-clean.bat`。

## 🔧 想自己改点东西

### 加一个自己的站点

项目支持通用站点采集器，不用写代码：

```bash
python -m cacx site list                    # 看已注册站点
python -m cacx site probe <URL>             # 探测某页面能否被采集
python -m cacx site add --id mysite --name "我的站点" --url https://...
```

或者直接在网页「数据同步 → 添加站点」里填。

### 中文检索是怎么做的

SQLite FTS5 的 `trigram` 分词器对中文有效，但**要求查询词 ≥ 3 个字符**——
实测 2 字词（如「清朗」）命中数为 0。所以做了两级降级：

| 查询 | 走法 | 实测 |
| --- | --- | --- |
| `数据出境负面清单` | FTS5 全文索引 | 18 条 / 24ms |
| `网信办` | FTS5 全文索引 | 9241 条 / 122ms |
| `清朗` | LIKE 扫描兜底 | 2419 条 / 404ms |

**混合查询时按最长的短板决定**：只要有一个词短于阈值，整条查询退回 LIKE，
避免半边走索引半边半边扫描导致漏结果。

### 跑测试

```bash
python （测试）\_regress.py            # 全量回归（48 个文件 / 765 项）
python （测试）\selftest.py            # 29 项自检
python （测试）\tests_generic.py       # 或各测试文件单跑
```

> ⚠ 被测文件在 `（测试）/` 子目录，但**运行目录必须是项目根**
> —— 部分测试要读 `config/settings.json`、`data/cacx.db`、`cacx/web/static`。
> `_regress.py` 已经自己 `chdir` 到根了，手动单跑时记得先回到项目根。
