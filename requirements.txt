# 核心依赖 —— Python >= 3.8 即可运行

# ⚠ 版本下限是查出来的，不是拍脑袋写的。`_pyfloor_probe.py` 的实测结论：
#   · cacx 发布代码里没有任何 3.9/3.10 专有构造（无 match 语句、
#     无运行期 | 类型注解、无 removeprefix 等新标准库 API）
#   · 唯一要求 3.10 的是 mcp，已拆到 requirements-mcp.txt
#   · 本包列出的依赖都有支持 3.8 的历史版本，pip 会按 Requires-Python
#     自动解析到与运行中的解释器匹配的那一版，无需在这里钉上限
#     （钉了反而可能在 3.13 上白白降级）
#
# 装不上/装到不兼容的版本时，请看 docs\STARTUP-GUIDE-zh.md 的排查小节。

beautifulsoup4>=4.12
